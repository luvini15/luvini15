## 👨‍💻 About Me

I'm **Luis Vinicius Hernani**, a Data Science student at Centro Universitário de Brasília focused on Machine Learning, Artificial Intelligence and data-driven solutions.

I have hands-on experience with **Python, SQL and Power BI**, working across the full data workflow: analysis, visualization, predictive modeling and Machine Learning, turning complex data into insights that support real decisions.

Lately I've been moving deeper into **AI Engineering**: building LLM-powered applications with RAG, AI agents and production-oriented backends using LangChain, LangGraph, FastAPI, PostgreSQL/pgvector and Docker.

- 🔭 Currently building AI and Data Science projects
- 🤖 Exploring AI Agents and RAG architectures
- 🧠 Focused on Machine Learning and AI Engineering
- 📊 Experienced with data analysis and visualization
- 🌎 Open to international opportunities
